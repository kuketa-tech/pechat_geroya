# Печать героя — документация для жюри

Веб-тренажёр слепой печати с геймификацией и AI-тренером. Кейс «Печать героя»,
отборочный этап хакатона «Киберрывок 2026».

Ниже: как запустить проект за пару минут, что нажать, чтобы увидеть каждую функцию,
и где в коде реализован каждый пункт технического задания.

---

## 1. Запуск

### Что нужно

- **Python 3.10 или новее** ([python.org](https://www.python.org/downloads/); на Windows при установке
  отметьте «Add python.exe to PATH»).
- Интернет — только при первом запуске, чтобы поставить зависимости (FastAPI, scikit-learn и др.).
- Современный браузер: Chrome, Edge, Firefox или Safari.

Ничего собирать не нужно: Node.js, npm и база данных не требуются. SQLite встроен в Python,
а база создаётся сама.

### Windows — в один клик

Дважды щёлкните **`run.bat`** в корне проекта. При первом запуске скрипт создаст окружение
`.venv` и поставит зависимости (1–2 минуты), затем запустит сервер и откроет браузер
на <http://127.0.0.1:8000>. При следующих запусках сервер стартует сразу.

### macOS и Linux — в одну команду

```bash
sh run.sh
```

Затем откройте <http://127.0.0.1:8000>.

### Вручную (любая система)

```bash
python -m venv .venv
```

Активируйте окружение: на Windows `.venv\Scripts\activate`, на macOS и Linux `source .venv/bin/activate`.

```bash
pip install -r backend/requirements.txt
```

```bash
uvicorn backend.main:app
```

Откройте <http://127.0.0.1:8000>. Остановить сервер — `Ctrl+C`.

Сервер раздаёт и сайт, и API на одном порту. Документация API (Swagger) — <http://127.0.0.1:8000/api/docs>.
База данных создаётся при первом запуске в `data/pechat.db`. В неё сразу добавляются 48 демо-соперников,
чтобы таблица лидеров не была пустой.

### Если что-то пошло не так

| Проблема | Что сделать |
|---|---|
| `python` не найден | Установите Python 3.10+ с отметкой «Add to PATH» или запускайте через `py` вместо `python` (Windows) |
| Порт 8000 занят | `uvicorn backend.main:app --port 8080` и откройте <http://127.0.0.1:8080> |
| Ошибка при установке scikit-learn или numpy | Обновите pip: `python -m pip install --upgrade pip`, затем повторите установку |
| Страница выглядит «старой» после обновления кода | Обновите страницу с очисткой кэша: `Ctrl+F5` |
| Хочется начать с чистой базы | Остановите сервер и удалите папку `data/`, база создастся заново |
| Нет интернета для шрифтов Google Fonts | Приложение работает, подставятся системные шрифты; Chart.js лежит в проекте локально |

## 2. Сценарий проверки (5–7 минут)

Чтобы сразу увидеть приложение «в работе», без долгой прокачки:

1. **Профиль → Демо и данные**:
   - включите «Открыть все режимы» — снимет ограничения по уровню;
   - нажмите «Заполнить» — появится история тренировок за 4 недели с логами нажатий
     (графики, тепловые карты, достижения, выводы AI-тренера).

Дальше по критериям оценки:

| Критерий | Что проверить |
|---|---|
| **Функциональность** | **Тренировка**: начните печатать. Таймер стартует с первой клавиши, зн/мин, сл/мин, точность и ошибки обновляются на лету. Ошибка подсвечивается красным, над буквой видно, что нажато, курсор ждёт верную клавишу. Переключите режим ошибок на «Свободный» — курсор пойдёт дальше, Backspace исправляет. В конце откройте окно итогов: скорость, точность, ошибки в начале/середине/конце, ошибки по рядам |
| **Режимы** | Слова, Предложения, Символы, Код (Python/JS/HTML/CSS), Умная, Свой текст; RU/EN; 30 с / 60 с / 2 мин / весь текст; на главной — «Испытание дня» |
| **Удобство** | Подсветка следующей клавиши цветом пальца и схема рук, светлая и тёмная темы (кнопки внизу сайдбара), мобильная вёрстка (сузьте окно до ширины телефона), пауза при потере фокуса, горячие клавиши `Esc` и `Tab` |
| **Геймификация** | Наберите 10, 25 и 50 символов без ошибок — комбо ×2, ×3, ×5 (на ×5 включается огненный режим). Случайные бонусы во время печати, опыт и уровни, достижения, задания дня, серия дней |
| **Статистика** | Страница «Статистика»: KPI за 7/30 дней и всё время, графики скорости и точности, тепловая карта ошибок по клавишам, трудные символы и сочетания, календарь активности, история |
| **Аккаунты** | Зарегистрируйтесь (email + пароль) — прогресс гостя перенесётся в аккаунт. Выйдите и войдите снова или войдите в другом браузере — прогресс тот же |
| **Рейтинг** | «Рейтинг»: скорость, точность, опыт, серия, испытание дня; фильтры «Сегодня / Неделя / Всё время» |
| **AI-тренер** | «AI-тренер», вкладка «Мои данные»: рекомендации, модель ваших ошибок и факторы риска, прогноз скорости, стиль печати, ритм по пальцам. Вкладка «Все игроки»: общие закономерности по всем игрокам. Кнопка «Начать» на рекомендации запускает подобранную тренировку |
| **Стабильность** | Ввод не перерисовывает текст (меняются 1–2 элемента), прогресс хранится в SQLite и переживает перезапуск сервера. Автотесты: `python -m pytest backend/tests -q` |

## 3. Соответствие техническому заданию

### 01. Режимы печати

| Требование | Реализация |
|---|---|
| Слова 2–10 букв из словаря | `frontend/js/data/texts.js` (словарь), `frontend/js/game/textgen.js` (фильтр по длине под сложность, перемешивание Фишера — Йетса) |
| Предложения на русском и английском | `texts.js` → `SENTENCES.ru / en`, 4 уровня сложности |
| Код: Python, JavaScript, HTML/CSS | `texts.js` → `CODE`; после Enter отступ пропускается автоматически |
| Символы: буквы, цифры, спецсимволы | `textgen.js` → `symbolsChunk`, набор зависит от сложности и раскладки |
| Переключение RU/EN | переключатель в тренажёре; при несовпадении раскладки нажатия не штрафуются, появляется подсказка |
| Дополнительно | «Умная» (ML), «Свой текст», «Испытание дня» |

### 02. Отображение текста и ввод

| Требование | Реализация |
|---|---|
| Текст посимвольно | каждый символ — отдельный элемент, `frontend/js/pages/trainer.js` |
| Подсветка: зелёный — верно, красный — ошибка | плюс подсветка текущего символа и слова, янтарный — исправленный символ (`frontend/css/trainer.css`) |
| Клавиатура с подсветкой пальцев | `frontend/js/ui/keyboard.js`: следующая клавиша и нужный Shift цветом пальца, схема рук, подпись «Левый мизинец · «ф»» |
| Звуковые и визуальные сигналы ошибки | синтезированный звук (`ui/sound.js`), вспышка и тряска поля, красная клавиша |
| Засчитываются только верные символы | строгий режим (по умолчанию): курсор ждёт верную клавишу, ошибка фиксируется; свободный режим — пропуск фиксируется как ошибка |

### 03. Игровая механика

| Требование | Реализация |
|---|---|
| Очки за правильный символ | 10 очков × множитель; итог P = C·M + B (бонус за завершение и точность), `game/scoring.js` |
| Комбо ×2, ×3, ×5 | пороги 10 / 25 / 50 нажатий без ошибок, анимации и огненный режим |
| Уровни, открытие режимов и сложностей | `data/modes.js`: «Символы» со 2 уровня, «Код» с 4-го, сложности «Боец» / «Ветеран» / «Легенда» с 3 / 6 / 10 уровня |
| Достижения | 27 штук (`data/achievements.js`), в том числе «Стальной палец» (1000 нажатий подряд), «Скорость звука» (200 зн/мин), «Печатный гений» (300 сл/мин) |
| Случайные бонусы | `game/bonuses.js`: двойной опыт на 10 с, +50% очков на 15 с, щит комбо, +5 секунд |

### 04. Статистика

| Требование | Реализация |
|---|---|
| Текущая сессия: зн/мин, сл/мин, точность, ошибки | HUD тренажёра и окно итогов |
| Общая: тренировки, время, прогресс по скорости | «Статистика» и «Профиль» |
| Анализ трудных символов | `backend/game/analysis.py`: сглаживание байесовским априорным распределением, учёт давности, ранжирование по нижней границе интервала; плюс ML-модель ошибок |
| Графики за дни и недели (Chart.js) | `frontend/js/pages/stats.js`, Chart.js 4.4.1 лежит в `frontend/vendor/` |

### 05. Аккаунты и прогресс

| Требование | Реализация |
|---|---|
| Регистрация по email или через соцсети | `backend/api.py`: email + пароль (хэш scrypt). Вход через VK ID, Яндекс, Google, GitHub — демонстрационный, без настоящего OAuth |
| Хранение прогресса в БД | SQLite: таблицы `users`, `progress`, `trainings`, `auth_tokens` (`backend/db.py`) |
| Синхронизация между устройствами | прогресс привязан к аккаунту на сервере: войдите с другого устройства или браузера — данные те же |
| Восстановление прогресса при входе | проверено автотестом `test_register_login_persist_and_isolation` |

### 06. Таблица лидеров

| Требование | Реализация |
|---|---|
| По скорости (зн/мин и сл/мин) | метрика «Скорость», колонка «Слов/мин» |
| По точности | метрика «Точность» |
| По опыту | метрика «Опыт» |
| Фильтры: сегодня, неделя, всё время | переключатель периода |
| Дополнительно | рейтинг по самой длинной серии и рейтинг испытания дня; подозрительные результаты (ритм автоввода) в рейтинг не попадают |

### Стек

| Слой | Технологии |
|---|---|
| Фронтенд | Vanilla JS (ES-модули, без сборки), CSS с дизайн-токенами, Chart.js |
| Бэкенд | Python, FastAPI, Uvicorn |
| База данных | SQLite |
| Машинное обучение | scikit-learn, NumPy, SciPy |
| Тесты | pytest |

## 4. Тесты

```bash
python -m pytest backend/tests -q
```

Ожидаемый результат — `7 passed`. Каждый тест поднимает приложение на своей временной базе и проверяет:

- регистрацию и вход;
- сохранность прогресса после выхода и после перезапуска;
- изоляцию данных разных пользователей;
- перенос прогресса гостя в аккаунт;
- все метрики рейтинга;
- отказ на невозможной скорости;
- пометку роботизированного ритма;
- выводы ML по одному игроку и по всем.
